# FACSUM Web Interface: User Manual

**Palomar Observatory · Caltech**

| | |
|---|---|
| **Telescope** | P200 Hale, Palomar Mountain |
| **Platform** | Browser-based (PHP / JavaScript) |
| **Revision** | 1.5 · September 2026 |

FACSUM (Facility Summary) is a browser-based observing tool for the Palomar
Observatory 200-inch Hale Telescope (P200). It combines live TCS telemetry,
target list management, a real-time sky display and an airmass plot in a single
page.

A print-ready version of this manual is available as a PDF:
{download}`FACSUM_User_Manual_Rev1.5.pdf <../User_Manual/FACSUM_User_Manual_Rev1.5.pdf>`.
