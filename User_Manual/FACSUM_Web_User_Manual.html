1Introduction

1.1 Overview

FACSUM (Facility Summary) is a browser-based observing tool for the Palomar Observatory 200-inch Hale Telescope (P200). It brings four key observing-support functions together in a single page:

  • Live monitoring of P200 Telescope Control System (TCS) telemetry — pointing, time, dome and instrument status
  • Loading and managing observer target lists, with real-time airmass computation for each target
  • A live sky display showing the azimuthal projection of the sky, telescope pointing, and the all-sky camera feed
  • An airmass plot showing when each target is best observable across the night

FACSUM runs as a web server on Observer1 (observer1.palomar.caltech.edu) and is accessed from the Portal workstation. The startup script start_facsum.sh (run on Portal) opens the SSH tunnel and launches Firefox automatically — no manual browser navigation is required. FACSUM is not directly reachable from outside the Palomar control room network.

1.2 Interface Layout

The interface is divided into four panels arranged in two columns. Each panel has a coloured accent to help orient quickly:

PanelPositionAccentPurpose
P200 TelemetryLeft, topCyanLive TCS data: pointing, time, dome and hardware status
Target ListsLeft, bottomOrangeLoad, view, and send targets to the telescope
Sky DisplayRight, topPurpleReal-time sky projection with all-sky camera overlay
Airmass PlotRight, bottomPurpleTarget observability curve across the night

Resizing panels: Three drag handles let you redistribute screen space to suit your workflow. Drag the vertical bar between the two columns to adjust their widths. Drag either horizontal bar within the left or right column to adjust how space is split between the panels above and below it.

The Airmass Plot section can be collapsed by clicking its header bar, freeing additional vertical space when not needed.

2Quick Start

The following steps describe the typical workflow at the start of a night run.

  1. Launch FACSUM. On the Portal workstation, run start_facsum.sh. The script establishes the SSH tunnel to Observer1 and automatically opens FACSUM in a Firefox window. The interface loads and connects to the TCS — live telemetry begins updating immediately.
  2. Verify the connection. Confirm the green Connected indicator in the Telemetry panel header. If the panel shows Disconnected, click Connect to re-establish.
  3. Load your target list. Click + Load Target List in the Target Lists panel. This opens the file browser (§7), where you can navigate the Observer1 filesystem and open your target file. FACSUM parses the file and populates the table automatically. See §4.1 for alternatives.
  4. Check target observability. The Targets Table shows a live airmass for each object. The Airmass Plot (right column, bottom) shows the selected target's visibility curve across the night. Sort the table by airmass to find the best target for right now.
  5. Select a target. Click any table row to select it. The selected target appears highlighted on the sky display with a crosshair, and its airmass curve is drawn in the plot below.
  6. Send the target to the telescope. With a row selected, click Load to Telescope. This sends a COORDS command to the TCS, loading the target's coordinates.
Important — COORDS does not slew: Sending a target with Load to Telescope loads coordinates into the TCS but does not move the telescope. Initiate the slew separately in the TCS software (e.g. TCSNG) before observing.

3Telemetry Panel

3.1 Connecting to the TCS

FACSUM connects to the TCS automatically on startup. If the connection is lost or was manually stopped, click Connect in the panel header to restart the background daemon and resume polling. A status LED and label on the right side of the header reflect the current connection state, colour-coded to match:

LED colourStateMeaning
● Red (static)DisconnectedDaemon not running; no TCS connection
● Yellow (pulsing)Connecting…Daemon starting or establishing the TCP connection to the TCS
● Green (pulsing)ConnectedPolling TCS successfully; all fields update continuously

The LED pulses slowly while connected and faster while connecting, providing a passive at-a-glance indication that the link is live. It is static (non-pulsing) when disconnected.

Click Disconnect to stop the daemon cleanly and release the TCS connection.

Note: Keep only one browser tab connected at a time. A second tab opening a connection will conflict with the daemon already started by the first.

4Target Lists Panel

4.1 Loading a Target File

There are two ways to get a target list into FACSUM:

  • From Observer1 (recommended): Click + Load Target List in the panel header. This opens the file browser (§7), which gives you direct access to the Observer1 filesystem. Navigate to your target file and click Open. FACSUM reads and parses the file automatically.
  • By pasting text: Click the Edit Text tab, paste or type your target list, and click ↺ Parse Text. This is useful for quickly trying a short list without saving a file.

Once a target list is loaded, the Save Target List button in the panel header becomes active. Clicking it opens the file browser in save mode, allowing you to write the current (possibly edited) target text to any filename on Observer1 — either overwriting the original file or saving to a new one. The filename of the currently loaded list is always shown in the upper-right corner of the panel header (e.g., targets123.csv); it reads — when no list is loaded.

FACSUM supports three file formats — CSV, PTIC, and NGPS — and auto-detects the format of any file you open. See Appendix A for the full format specification.

4.2 Parse Options

The strip below the tab bar lets you control how the file is parsed. In most cases the defaults work without adjustment.

Sorting

Click any column header to sort by that column — click once for ascending, again for descending, and a third time to restore the original order. An arrow (▲ / ▼) marks the active sort column. Sorting by Airmass is a quick way to find the most observable target right now.

Selecting a target

Click a row to select it (it highlights in orange). Click it again to deselect. Only one target can be selected at a time. Selecting a target:

  • Draws a larger dot and crosshair for that target on the sky display
  • Draws that target's airmass curve in the Airmass Plot
  • Makes the Load to Telescope button appear (§4.5)

Adding a single target manually

Click + Add Single Target at the bottom of the table to open a data-entry form. Fill in the Name, RA, Dec, Epoch, and optional rate/notes fields, then click Add. The new target is appended to the list and immediately available for selection and sending. This is useful for adding a target of opportunity without editing the text file.

Deleting a target

Select a row, then click − Delete Selected (adjacent to the Add button) to remove it from the list. The deletion cannot be undone from the table view; use the Edit Text tab (§4.4) and its Undo button if needed.

Clearing the target list

Click ✕ Clear List (separated by a | from the Delete button) to unload the entire target list. This removes all rows from the table, clears the Edit Text area, hides the Observed column, resets the filename display to —, and resets the SFTP file browser back to /observer/observer/targets so the next Load Target List opens there. The sky display and airmass plot also clear immediately. This action cannot be undone.

4.4 Edit Text Tab

The Edit Text tab shows the raw text of the loaded target list and lets you edit it directly. A live syntax-highlighting overlay colours each line as you type:

  • Green — line was successfully parsed as a target
  • Red — line could not be parsed (check format or delimiter settings)
  • Dimmed — comment line (starts with # or !) or blank line

Three action buttons appear at the bottom of the Edit Text pane:

  • ↩ Undo / ↪ Redo — step backward or forward through the editing history (equivalent to Ctrl+Z / Ctrl+Y)
  • ↺ Parse Text — apply the current text and switch back to the table view

4.5 Sending a Target to the Telescope

When a table row is selected, the Load to Telescope button appears below the parse options bar. Clicking it sends a COORDS command to the P200 TCS via a direct network connection (see Appendix B for the command format).

The button shows a brief status as the command is processed:

  • Sending… — command is in flight; button is temporarily disabled
  • Target Loaded! — TCS acknowledged the coordinates; the Loaded block in the Telemetry panel updates, and a ✓ is placed in the target's Observed column (see §4.6). Reverts to normal after 2 s.
  • Error — command failed; check the network connection or server log (reverts after 2.5 s)
Two things to check before sending:
  • Apply Rates must be checked for non-sidereal tracking rates to be included. If it is unchecked, or if Rate Units is set to Proper Motion, zero rates are sent regardless of the values in the file.
  • COORDS loads coordinates but does not slew the telescope. Issue a separate slew command in the TCS software after sending.

4.6 Observed Column

When a target list is loaded, the first column of the table shows a ✓ (check mark) for each target that has been observed during the session. The column is hidden when no list is loaded.

  • Automatic marking: when a target is successfully sent to the telescope via Load to Telescope and the TCS acknowledges the command, its row is marked automatically.
  • Manual toggle: click the ✓ cell of any row to add or remove the mark by hand — useful for correcting the record or marking targets observed by other means.
  • Row highlight: observed rows are tinted faint orange to make them visually distinct from unobserved targets at a glance.
  • Session only: the observed state is held in memory and is not written to the target file. Loading a new target list resets all marks.

5Sky Display

5.1 Sky Projection & Grid

The sky canvas uses an azimuthal equidistant projection looking straight up from Palomar Mountain. The zenith is at the centre; objects closer to the horizon appear closer to the edge of the circle.

Orientation follows standard astronomical convention: North is up, East is to the left. The grid rotates with sidereal time, so an object transiting the meridian appears near the centre-top of the display, and objects at large hour angles appear toward the east or west edges.

5.2 All-Sky Camera Overlay

Check AllSky in the panel header to overlay the live Palomar all-sky camera image on the sky projection. The image is fetched every 30 seconds via a server-side proxy and composited at 55% opacity, with geometry corrections applied to align the fisheye lens image with the equidistant grid.

If the camera is unreachable (daytime, dome closed, network outage), the overlay is silently omitted and the most recent successful image is retained until a new one arrives.

5.3 Markers (Moon, Sun & Planets)

Click Markers in the panel header to open a small dropdown with two checkboxes:

  • Moon — renders a phase-accurate lunar disc at the computed lunar position. The illuminated fraction and orientation are calculated from the Sun–Moon geometry, so the disc reflects the current phase (crescent, quarter, gibbous, full, etc.). Position is calculated using the Meeus simplified algorithm (accuracy ≈ ±1°).
  • Sun & Planets — draws yellow dots for the Sun, Mercury, Venus, Mars, Jupiter, Saturn, Uranus, and Neptune, with marker radii scaled approximately by apparent size. Positions use Keplerian orbital elements (Meeus Table 31.a, accuracy ≈ ±1–2°). All calculations are done in the browser from the current time; no external ephemeris service is needed.

Bodies below the horizon are not drawn. Toggle Labels in the header to show or hide body name labels next to each marker.

5.4 Zoom & Pan

Three buttons in the lower-left corner of the sky canvas control the view level:

ButtonAction
− (Zoom out)Shrinks the sky circle within the pane (÷ 1.6 per click)
⌂ (Reset)Returns to the default full-view with no zoom or pan offset
+ (Zoom in)Enlarges the sky circle within the pane (× 1.6 per click)

When zoomed in, click and drag on the canvas to pan. The cursor changes to a grab icon when panning is available. The entire sky circle — grid, markers, cardinal labels, and all-sky overlay — scales and pans together uniformly.

6Airmass Plot

The Airmass Plot (below the sky canvas, collapsible) shows the observability of the selected target across the entire observing night. It updates in real time as the night progresses.

Night selection: FACSUM determines which night to display automatically. Before sunrise it shows the previous night (last sunset through the current time); after sunrise it switches to the upcoming night (today's sunset through tomorrow's sunrise).

6.1 Reading the Plot

ElementDescription
X-axisUT hours across the night (top row), with Pacific Time equivalents below
Y-axisAirmass from 1.0 (zenith) to 4.5 (near horizon). Lower is better.
Dark blue shadingTwilight bands — observation is typically avoided in these regions
Orange dashed linesExact sunset and sunrise times
Light blue dashed lineCurrent time; "NOW" label appears in the time-axis margin just below the plot
Yellow dashed lineMoon's airmass across the night (shown when Moon marker is enabled)

White dot on curveCurrent airmass at the NOW line, with a numeric label

If no target is selected, the plot area shows the message "Select a target to view its airmass curve."

6.2 Scrolling the Time Axis

The plot can be panned horizontally to inspect earlier or later parts of the night:

  • Drag left/right inside the plot to scroll the time axis. The cursor changes to a grabbing hand while dragging.
  • Click the ⌂ home button (bottom-left of the plot) to snap back to the default view centred on the current night.

The NOW line, twilight shading, and all curves scroll together so relative timing is always clear.

6.3 Interactive Cursor

Hover the mouse over the plot to read off values at any time during the night:

  • A cyan hairline follows the mouse horizontally
  • A time label (e.g. 04:30 UT) appears at the bottom of the plot at that position
  • A floating airmass label shows the target's airmass at that time

Moving the mouse out of the plot area dismisses the cursor. Hovering does not interfere with drag-to-pan — a small drag threshold (4 px) distinguishes the two gestures.

FACSUM accepts any plain-text target file in CSV or PTIC format (see Appendix A). File extensions (.csv, .ptic, .txt, etc.) are not significant — format is detected from the file content automatically.

AAppendix A — Target File Formats

FACSUM supports two plain-text target list formats. Both accept comment lines beginning with # or !, and inline comments after a ! on any data line. Fields after the ! are treated as notes and are shown in the Notes column of the table.

A.1 CSV Format

Tabular data with consistent column separators (comma, semicolon, tab, space, or a custom character). Fields are positional and parsed left-to-right:

#FieldRequired?FormatExample
1NameYesAny string; quote if it contains the delimiterHZ Her
2RAYesHH:MM:SS.s or HH MM SS18:10:28.1
3DecYes±DD:MM:SS or DD MM SS+30:48:22
4EpochNoJ2000, B1950, or a numeric year (defaults to 2000)2000
5Rate / PM RANoNumeric; units set by Rate Units control0.00
6Rate / PM DecNoNumeric0.00
7+NotesNoAny remaining text, or text after !Flux std

Example — comma-separated:

# Name,         RA,          Dec,        Epoch
HZ Her,       18:10:28.1,  +30:48:22,  2000
NGC 6543,     17:58:33.4,  +66:37:59,  2000   ! Cat Eye Nebula
Feige 110,    23:19:58.4,  -05:09:56,  2000   ! Flux standard

A.2 PTIC Format

Fixed-width format used by the original FACSUM and the Palomar TCS catalog system. The target name occupies the first 17 characters (space-padded); coordinates and optional fields follow as space-separated tokens.

ColumnsFieldNotes
0 – 16Name (17 chars)Space-padded to the right
17+RAThree tokens: HH MM SS.s
DecThree tokens: ±DD MM SS
Epoch (optional)Defaults to 2000 if absent
Rates (optional)Two numeric values; units set by Rate Units control
Notes (optional)Remaining text, or text after !

Example:

# Name              RA                 Dec             Epoch
HZ Her            18 10 28.1  +30 48 22   2000
NGC 6543          17 58 33.4  +66 37 59   2000  ! Cat Eye Nebula
BD+28 4211        21 51 11.0  +28 51 50   2000
Feige 110         23 19 58.4  -05 09 56   2000  ! Flux standard
Auto-detection preference: When both CSV and PTIC parse a file equally well, PTIC is preferred. If auto-detection picks the wrong format, select the correct one explicitly with the File Type radio buttons.

A.3 NGPS Format

Column-based format used by the Next Generation Palomar Spectrograph (NGPS) observing tool. FACSUM recognises it automatically from the presence of a header row whose first three columns are NAME, RA, and DECL.

Unlike CSV and PTIC, NGPS coordinates are given in decimal degrees (not sexagesimal). FACSUM converts them internally when displaying and sending to the TCS.

ColumnRequired?Description
NAMEYesTarget name
RAYesRight Ascension in decimal degrees (J2000)
DECLYesDeclination in decimal degrees (J2000)
OFFSET_RANoRA offset (arcsec)
OFFSET_DECNoDec offset (arcsec)
COMMENTNoFree-text comment, shown in Notes column
PRIORITYNoInteger priority; shown in an extra Priority column
MAGNITUDENoObject magnitude
MAGFILTERNoFilter band for the magnitude value
EXPTIMENoExposure time (seconds) or SNR <value>

When an NGPS file is loaded, the Targets Table adds two extra columns — Priority and Mag / Filter — if those columns are present in the file header. Both comma-separated and space-delimited NGPS files are supported.

Example — space-delimited:

# NGPS target list
NAME             RA         DECL       COMMENT          PRIORITY  MAGNITUDE  MAGFILTER  EXPTIME
HZ_Her           272.6170   30.8061    X-ray_binary      1         8.9        V          600
NGC_6543         269.6392   66.6330    Cat_Eye_Nebula     2        11.2        V          300

BAppendix B — TCS COORDS Command Reference

When Load to Telescope is clicked, FACSUM sends a COORDS command to the TCS over a direct TCP connection on port 49200. The full command format is: 

COORDS  <RA_h>  <Dec_deg>  <epoch>  <rate_RA>  <rate_Dec>  [mflag]  '<name>'
ArgumentTypeDescription
RA_hFloatRight Ascension in decimal hours
Dec_degFloatDeclination in decimal degrees (negative = south)
epochFloatCoordinate epoch (e.g. 2000.0)
rate_RAFloatRA rate; 0.0 if rates are not applied
rate_DecFloatDec rate; 0.0 if rates are not applied
mflagInteger (optional)Motion flag: absent = proper motion; 1 = arcsec/hr both axes; 2 = RA in sec/hr, Dec in arcsec/hr
nameStringTarget name in single quotes

Examples

Sidereal target, no rates:

COORDS  18.174472  30.806167  2000.0  0.0  0.0  'HZ Her'

Non-sidereal target with arcsec/hr rates (mflag 1):

COORDS  10.884722  14.235000  2000.0  12.4  -3.1  1  'Mars'

Non-sidereal target with sec/hr RA rate (mflag 2):

COORDS  10.884722  14.235000  2000.0  0.83  -3.1  2  'Mars'
Reminder: COORDS loads coordinates into the TCS but does not move the telescope. Always issue a separate slew command in the TCS software after sending.
